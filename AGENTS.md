# Repository Instructions

- Static landing page for the Andalucia jewelry brand.
- No package manager, framework, build step, lint config, or test runner is configured.
- Main files: `index.html`, `styles.css`, and `script.js` in the project root.
- Product data is managed via the admin panel (`/admin`) and API.
- The admin panel is at `admin.html`, backed by `admin.js` and `admin.css`.
- The server runs on Node.js + Express; use `npm run dev` to start.
- Docs are in `docs/` — see `instalacion.md`, `base-de-datos.md`, `cloudinary.md`.
